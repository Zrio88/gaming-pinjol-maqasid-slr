# Appendices A–E — index

The manuscript cites five appendices. All of them are hosted in this repository,
so that a reader or reviewer can move from any in-text appendix reference to the
underlying material. Nothing here adds new data; it collects and labels the files
already present under `data/`, `search/`, and `protocol/`.

| Appendix | Title (as cited in the manuscript) | Repository file(s) |
|----------|------------------------------------|--------------------|
| **A** | Search log — verbatim database search strings | `search/search-strategies.md` |
| **B** | Evidence table — extraction of the 36 included studies (S01–S36) | `data/included-studies.csv`; per-table views in `data/table2-international-empirical.csv`, `data/table3-indonesian-empirical.csv`, `data/table4-legal-normative-maqasid.csv`; appraisals in `data/quality-appraisal.csv` (Table 5) and `data/certainty-of-evidence.csv` (Table 6) |
| **C** | Protocol appendix — inclusion/exclusion rubric and codes E1–E9; extraction codebook | `protocol/protocol-summary.md`; `protocol/inclusion-exclusion-codes.md`; `protocol/codebook.md`; eligibility table in `data/eligibility-criteria.csv` |
| **D** | Completed PRISMA 2020 checklist | `appendices/appendix-D-prisma-2020-checklist.md` |
| **E** | Screening log — stage decisions and exclusion reasons | `search/screening-log.md`; machine-readable counts in `data/prisma-flow.csv` |
