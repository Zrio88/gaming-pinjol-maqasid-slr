# Eligibility criteria and exclusion codes

## Operational inclusion criteria (all must hold)

1. Addresses online gaming (not merely online gambling).
2. Addresses lending / indebtedness / consumer-credit or financial behaviour.
3. Links gaming to financial outcomes, or supplies a conceptual framework that
   does so.
4. Is a legitimate source type (peer-reviewed article, conference paper, book
   chapter, thesis, or official report).
5. Falls within the 2015–2026 publication window.

## Operational exclusion criteria (any one suffices)

| Code | Exclusion reason |
|------|------------------|
| **E1** | Off-topic |
| **E2** | Duplicate / updated version |
| **E3** | Non-retrievable full text |
| **E4** | No extractable data |
| **E5** | Wrong population |
| **E6** | Opinion without framework |
| **E7** | Predatory venue |
| **E8** | Language other than Indonesian/English |
| **E9** | Outside date window |

## Eligibility framework

Eligibility was defined by **PICOC** and operationalised through **PICOS**; see
`../data/eligibility-criteria.csv` for the element-by-element specification.
